## Foundations Through Credit Scoring

**Problem:** Predict whether a loan applicant will default.

**What you learn:**
- [x] Python + pandas for data wrangling
- [ ] Exploratory data analysis (EDA)
- [ ] Logistic regression (your first predictive model)
- [ ] Feature engineering (income ratios, employment length, credit utilisation)
- [ ] Train/test split, cross-validation
- [ ] Evaluation metrics: accuracy, precision, recall, AUC-ROC
- [ ] Handling imbalanced classes

**Dataset:** Lending Club or German Credit dataset (both freely available)

**Deliverable:** A model that scores applicants with a probability of default, plus a report explaining which features matter most.
